# Under the Hazel Tree

A small, slow website for poems, stories and quiet reflections — built with
[Astro](https://astro.build) and hosted on [Cloudflare Workers](https://developers.cloudflare.com/workers/).

Live site: <https://underthehazeltree.com>

## What's in here

| Path | What it is |
| --- | --- |
| `src/content/{poems,stories,journal}/` | The writing. One Markdown file per piece. |
| `src/content.config.ts` | Frontmatter schema for all three collections. |
| `src/pages/` | Routes. Everything is prerendered except `/wander`. |
| `src/layouts/`, `src/components/` | Page shells and the shared building blocks. |
| `src/styles/global.css` | The whole design system — colours, type, components. |
| `scripts/art.mjs` | Generates every illustration in `public/img` as SVG. |
| `public/img/` | Generated artwork (committed, so builds need no network). |

Pages are static; the one Worker route is `/wander`, which picks a piece at
random and redirects to it.

## Running it

```bash
npm install
npm run dev          # http://localhost:4321
```

Other scripts:

```bash
npm run build        # production build into dist/
npm run preview      # preview the built site in the Workers runtime
npm run check        # Astro + TypeScript diagnostics
npm run art          # regenerate the illustrations
```

## Adding a piece

Drop a Markdown file into `src/content/poems/`, `src/content/stories/` or
`src/content/journal/`. The filename becomes the URL.

```markdown
---
title: Winter Hazel
date: 2025-12-21
excerpt: "Bare, the tree shows its working."
art: winter-hazel
tags: [winter, hazel]
draft: false
---

Bare, the tree shows its working:
every decision it ever made
about the light,
```

- `art` is the basename of any SVG in `public/img/` — it's used for the card
  thumbnail, the header image and the social preview.
- `draft: true` keeps a piece out of production builds while still showing it in
  `npm run dev`.
- **Poems keep their line breaks.** Markdown preserves the newlines inside a
  paragraph and the `.verse` styling honours them, so write the lines as you
  want them read; leave a blank line between stanzas.

## The illustrations

There are no stock photos here. Every image is generated by `scripts/art.mjs`,
which draws scenes — hills, woodland, a road, a pool, bogland, a desk by a
window — out of seeded randomness, so the output is deterministic and
regenerating never produces a spurious diff.

To add or change artwork, edit the `artwork` map at the bottom of the script and
run `npm run art`. Committing the results keeps the build offline-friendly.

## Deploying

The site builds to a Cloudflare Worker with static assets. The build writes a
ready-to-deploy Wrangler config to `dist/server/wrangler.json`.

```bash
npx wrangler login   # once
npm run deploy
```

`npm run deploy` runs the Astro build and then
`wrangler deploy -c dist/server/wrangler.json`.

### Custom domain

After the first deploy, in the Cloudflare dashboard go to **Workers & Pages → underthehazeltree
→ Settings → Domains & Routes** and add `underthehazeltree.com` (and `www` if you
want it). Cloudflare issues the certificate; the DNS records are created for
you when the domain is on the same account.

### Deploying from GitHub

`.github/workflows/deploy.yml` builds and deploys on every push to `main`. It
needs two repository secrets:

| Secret | Where to get it |
| --- | --- |
| `CLOUDFLARE_API_TOKEN` | Cloudflare dashboard → My Profile → API Tokens → *Edit Cloudflare Workers* template |
| `CLOUDFLARE_ACCOUNT_ID` | Workers & Pages overview, right-hand column |

Delete the workflow if you'd rather deploy from your own machine.

## Notes

- Fonts (Cormorant Garamond and EB Garamond) are self-hosted via Fontsource, so
  no request ever leaves for a third-party font CDN.
- `/rss.xml`, `/sitemap-index.xml` and `robots.txt` are generated at build time.
- Long-lived caching for hashed assets is set in `dist/client/_headers`, which
  the Cloudflare adapter writes during the build.
